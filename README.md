# スクショ整理 (screenshot-cleaner)

AIに画面の状況を伝えるために撮ったスクリーンショットは、使い終わってもたまりがちです。
このツールは今日（または直近1〜7日）のスクショをすぐ一覧表示し、まとめて削除できます。
ストレージの圧迫と、古いスクショとの取り違えを防ぎます。

Windows 10 / 11 用です。追加のソフトは不要で、標準の Windows PowerShell で動きます。

## インストール

1. このリポジトリの `ScreenshotCleaner.ps1` と `install.bat` を、同じフォルダにダウンロードします。
2. `install.bat` をダブルクリックします。

次の3つが登録されます。

- デスクトップの「スクショ整理」アイコン
- スタートメニューの「スクショ整理」
- `ss` コマンド（Win+R、コマンドプロンプト、PowerShell から使えます）

本体は `%LOCALAPPDATA%\ScreenshotCleaner` にコピーされます。

## 使い方

### ウィンドウ

アイコンをクリックするか、`ss` と入力すると開きます。

- 起動直後は、今日のスクショがサムネイルで一覧表示されます。件数と合計容量も表示されます。
- 期間は「今日」から「直近7日」まで選べます。「それより古いもの」に切り替えると、指定した期間より前のものだけを表示します。
- チェックを入れて「チェックしたものを削除」を押すと削除します。
- 通常の削除はごみ箱への移動です。「完全に削除」にチェックすると、ごみ箱を使わずに削除します。

| 操作 | キー / マウス |
|---|---|
| すべてチェック | Ctrl + A |
| 選択中のチェックを切り替え | Space |
| 画像を開く | ダブルクリック / Enter |
| 再読み込み | F5 |

### コマンド

```
ss                          ウィンドウを開く
ss -List                    今日のスクショを一覧
ss -List -Days 3            直近3日分を一覧
ss -Delete -Days 1          今日の分をごみ箱へ（確認あり）
ss -Delete -Days 7 -Older   直近7日より古いものをごみ箱へ
```

| オプション | 内容 |
|---|---|
| `-Days N` | 期間（日数）。1 は今日、3 は一昨日の0時以降 |
| `-Older` | 期間内ではなく、期間より古いものを対象にする |
| `-Permanent` | ごみ箱を使わずに完全削除する |
| `-Force` | 削除前の確認を省略する |
| `-Folder "パス"` | 対象フォルダを指定する |

## 対象フォルダ

次の順番で探します。

1. 画面の「フォルダ変更…」で指定したフォルダ
2. Windows の「スクリーンショット」フォルダ（OneDrive に移動している場合も追従します）
3. `ピクチャ\Screenshots`

削除の対象は画像ファイル（png / jpg / jpeg / gif / bmp / webp）だけです。サブフォルダの中は見ません。

## アンインストール

```
ss -Uninstall
```

アイコン、`ss` コマンド、PATH の設定を削除します。スクリーンショット自体は削除しません。
